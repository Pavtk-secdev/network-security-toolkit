# Network Security Toolkit

Набор Python-утилит для базовых задач сетевой безопасности и администрирования:
анализ логов, обогащение IP-адресов данными из внешних API и инвентаризация сети.

## Стек

Python 3, `requests` (REST API, JSON), стандартная библиотека (`sqlite3`,
`argparse`, `concurrent.futures`, `ipaddress`, `re`).

## Установка

```bash
git clone <адрес-репозитория>
cd network-security-toolkit
pip install -r requirements.txt
```

## Скрипты

### 1. `failed_logins.py` — анализ неудачных входов по SSH

Читает журнал аутентификации, находит неудачные попытки входа по SSH
и выводит топ IP-адресов по количеству попыток. Помогает быстро заметить
брутфорс-атаку.

```bash
python3 failed_logins.py --file /var/log/auth.log --top 20
```

Пример вывода:

```
Всего неудачных попыток: 1487
Уникальных IP: 34

IP-адрес           Попыток
--------------------------
203.0.113.45           612
198.51.100.7           241
192.0.2.88             155
```

### 2. `ip_enrich.py` — обогащение IP гео и репутацией

Для каждого IP запрашивает страну и провайдера через ip-api.com, а также
оценку репутации через AbuseIPDB (нужен бесплатный API-ключ). Результаты
можно сохранить в SQLite для дальнейшего анализа.

```bash
# только гео (без ключа)
python3 ip_enrich.py --ips 8.8.8.8 1.1.1.1

# гео + репутация + сохранение в базу
ABUSEIPDB_KEY=ваш_ключ python3 ip_enrich.py --file ips.txt --db results.db
```

Ключ AbuseIPDB передаётся через переменную окружения `ABUSEIPDB_KEY`
и в коде не хранится.

### 3. `net_inventory.py` — инвентаризация сети

Пингует все адреса подсети в несколько потоков и выводит активные хосты.
Быстрый способ понять, какие адреса заняты в локальной сети.

```bash
python3 net_inventory.py 192.168.1.0/24 --workers 100
```

Пример вывода:

```
Сканирую 254 адресов в 192.168.1.0/24 ...

  [+] 192.168.1.1
  [+] 192.168.1.10
  [+] 192.168.1.50

Активных хостов: 3 из 254
```
